# AgentAI

Локальный агент на базе **OpenCode** с профилями API: Gwarden и другие провайдеры с OpenAI-совместимым API. AgentAI запускает настоящий OpenCode, а не имитирует его: диалог, работа с файлами и выполнение команд осуществляются инструментами OpenCode на вашем компьютере.

## Установка

Нужны Python 3.9+ и установленный [OpenCode](https://opencode.ai/docs/). Например, при наличии Node.js:

```bash
npm install -g opencode-ai
python -m pip install .
```

На Windows при необходимости используйте `py -m pip install .`. Запускайте команды из папки проекта AgentAI; после установки команду `agentai` можно вызывать из любой папки. Если установка Python-скриптов не добавлена в PATH, вместо `agentai` используйте `python -m agentai`.

## Подключение Gwarden

Получите ключ у [Gwarden](https://gwarden.su/) и в терминале выполните:

```bash
agentai add
agentai start
```

Ключ вводится скрыто, не вставляйте его в команду и не присылайте в чат. По умолчанию используется `https://gwarden.su/v1` и модель `deepseek-v4.1-flash-1017`. Проверьте доступность модели в своём тарифе и актуальный ID в каталоге Gwarden. Можно указать любую поддерживаемую модель с tool calling:

```bash
agentai add --model glm-5.3 --replace
agentai start
```

OpenCode открывается в **текущей папке терминала**. Пишите задачу на русском или другом языке. В обычном режиме AgentAI запрашивает подтверждение действий; чтобы продолжить, отвечайте на запросы OpenCode. Это не системная песочница.

## Полный доступ к компьютеру

```bash
agentai start --full-access
```

Введите `FULL` для подтверждения. Этот режим разрешает действия OpenCode, в том числе команды оболочки и доступ за пределы текущей папки, **без подтверждения отдельных действий**. Для автоматизированного запуска можно явно указать `--full-access --yes`.

Агент имеет только те права, которыми обладает пользователь, запустивший процесс: это не обход прав ОС, UAC или sudo, и не гарантия управления всеми GUI-приложениями. Команды могут удалить файлы, раскрыть данные или повредить систему. Не запускайте от администратора без необходимости; используйте резервные копии, проверяйте источники задач и лучше сначала испытайте в виртуальной машине. Модель может ошибиться или выполнить инструкции из недоверенного контента, а текст задачи и содержимое, которое ей передаётся, отправляются выбранному API-провайдеру. Системные/управляемые политики OpenCode могут ограничить доступ даже в этом режиме.

## Другие API и профили

Для другого **OpenAI-совместимого** сервиса укажите его HTTPS base URL и точный ID модели:

```bash
agentai add work --url https://api.example.com/v1 --model model-id
agentai list
agentai start --profile work
agentai remove work
```

`--replace` заменяет существующий профиль и его ключ. Укажите URL именно совместимого API, а не произвольную страницу; не все API, модели и функции tool calling совместимы. Ключ отправляется указанному хосту: используйте только проверенные адреса. Профили не проверяют ключ и доступность модели при добавлении.

Для разовой задачи вместо интерактивного интерфейса:

```bash
agentai start --message "Объясни структуру текущего проекта"
```

В неинтерактивном режиме OpenCode может отклонять запросы разрешений, если ответить на них невозможно; для работы с подтверждениями используйте обычный интерактивный запуск.

## Данные и безопасность

Профили, **включая ключи в открытом виде**, хранятся в `~/.config/agentai/profiles.json` (или `$XDG_CONFIG_HOME/agentai/profiles.json`; в Windows — `%APPDATA%\agentai\profiles.json`). На Unix файл создаётся с правами `0600`; на Windows доступ определяется ACL папки пользователя. Это не хранилище секретов ОС: защитите учётную запись и резервные копии. `remove` удаляет запись, но не гарантирует безопасного стирания старых копий на диске. При запуске ключ передаётся процессу OpenCode через переменную окружения и может быть доступен его дочерним процессам и другим процессам с достаточными правами. Не публикуйте файл профилей или журналы, которые могут содержать секреты.

AgentAI передаёт конфигурацию OpenCode через `OPENCODE_CONFIG_CONTENT`, не изменяя ваши конфиги. OpenCode также может загружать другие конфиги, плагины и политики текущего пользователя и проекта. Используйте только доверенные проекты и плагины. Проверка ключа и реальный ответ модели требуют работающего доступа к выбранному API.
